## Story

**As a** realtor,  
**I want** fast cross-CRM navigation, persisted pipeline actions and event-backed insights,  
**so that** I can find work, move deals and understand funnel health without decorative metrics or duplicate records.

**Traceability:** C-02, C-03; D-02, D-06; L-10, L-13; N-04, N-06 in the parity matrix.

**Dependencies:** Stories 3.1 and 3.2 provide searchable tasks/activities/incomplete records, workspace scope, archive state and assignment identity.

## Acceptance Criteria

1. A CLI search command queries the same bounded index/service used by the UI across contacts, tasks, incomplete records, Smart Lists, mailers and workspace members; results are workspace-scoped, type-labeled, permission-filtered, deterministically ranked and deep-linkable.
2. A global UI search/command surface exposes only an allowlist of navigation/actions: open a result, add contact/task, import contacts, create Smart List and open pipeline/work queue. It does not execute arbitrary text, SQL, scripts, provider sends or destructive actions.
3. Pipeline movement uses the existing validated contact command, persists canonical stage, appends one activity event and returns a receipt. Drag/drop and keyboard/button alternatives call the same command; failed persistence restores the prior UI state and announces the error. Cross-workspace, archived and stale-version moves fail closed.
4. The dense lead view shows real activity/task counters and assignment/state facts derived from stored records. A “dashboard” subset, if exposed, is a named system Smart List over the same source of truth, not a parallel membership flag or copied contact collection.
5. Funnel counts and stage-duration/source insights are computed only from stored stage/activity history. Conversion percentages declare numerator, denominator and date window; empty/insufficient data shows “not enough evidence.” Revenue, uptime, response time, visitor and agent-performance metrics remain absent until their own verified sources exist.
6. CLI and `/insights` produce matching aggregate values for the same workspace/window. Queries are bounded for the client's 200–500 contacts, indexed by workspace/stage/event time and do not load cross-workspace data.
7. Desktop/390px, pointer/keyboard and light/dark behavior cover global search, action surface, dense list and pipeline movement without removing existing route navigation. Loading, empty, stale, no-result, permission and persistence-error states are explicit.
8. Unit/integration tests cover ranking, action allowlist, stage transitions/receipts, optimistic rollback, counters, windowed funnel arithmetic and insufficient data. CLI smoke, browser regression, lint, typecheck, complete tests and build pass.

## Out of Scope

- Fixed/demo KPIs, revenue/P&L, website analytics, autonomous action execution or global destructive commands.
- Provider messages/calls, transactions/listings, custom dashboards or copied reference navigation/trade dress.
