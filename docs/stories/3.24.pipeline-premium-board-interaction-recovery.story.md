## Story

**As Judith,**  
**I want** a clear, premium pipeline board whose cards can actually be moved,  
**so that** I can understand deal flow and update a relationship stage with minimal effort on desktop or mobile.

**Traceability:** User-reported production regression on 2026-08-22; Story 3.3 AC 3 and AC 7.

## Acceptance Criteria

1. The Pipeline presents all seven canonical stages in one deliberate board flow with fixed-width, non-overlapping columns, clear counts and compact relationship cards.
2. Desktop pointer drag and drop moves a card to the intended stage, calls the existing canonical server action, persists the stage and announces success. Failed persistence restores the prior state and announces the failure.
3. Every card offers an equally capable keyboard/mobile “Move to” control using the same action. The control remains reachable without horizontal precision gestures.
4. A stage with many contacts does not render an unbounded vertical wall. The board progressively discloses cards, preserves the true total count and lets Judith reveal more without losing her place.
5. Search and lead-temperature filters operate only over the already-authorized contacts in memory, preserve the canonical stage grouping and state the visible result count.
6. Cards show the relationship name, lead temperature, intent and next action first. Stored task/activity evidence remains available through progressive disclosure without raw technical timestamps or overflowing strings.
7. Dragging has visible source/target feedback, respects reduced-motion preferences, does not create layout overflow and keeps a polite live status for assistive technology.
8. Automated tests cover successful movement, optimistic rollback, filtering, progressive disclosure and existing evidence states. Browser validation covers authenticated 390px, 768px and 1440px layouts plus a real pointer drag and persisted reload.
9. `npm run lint`, `npm run typecheck`, `npm test` and `npm run build` pass before release.

## Out of Scope

- New pipeline stages, automated deal valuation, transaction documents or provider messaging.
- A parallel board database, hidden membership flags or fabricated revenue/conversion metrics.
