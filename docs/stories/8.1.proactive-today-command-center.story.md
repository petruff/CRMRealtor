# Story 8.1 — Proactive Today Command Center

**Epic:** 8 — Governed AI Operating Layer
**Status:** Locally Complete — Authenticated Release UAT Pending
**Owner:** @dev with @ux-design-expert
**Quality Gate:** @qa + @architect

## Story

As Judith or her authorized assistant, I need one calm, prioritized command center that explains what can move the business today and links every claim to the exact saved record, so that I can act without scanning disconnected modules or trusting invented metrics.

## Acceptance Criteria

1. Today reads the canonical attention queue and preserves its P0–P4, due-time, aging, and FIFO order rather than creating a competing priority algorithm in the browser.
2. Approvals, inbound replies, transaction deadlines, nurture, active transactions, provider degradation, relationship growth, and explicit unknowns appear as bounded operational workstreams.
3. Every actionable summary links to its authoritative workflow; the top priority ledger links to each exact contributor and states its evidence count.
4. A failed source read remains visibly unavailable and cannot be presented as a verified zero.
5. Business pulse uses only stored contacts, stages, transactions, and verified facts. No decorative forecast, inferred deadline, invented GCI, or unsupported opportunity appears.
6. Progressive disclosure bounds the initial priority list to five durable items while preserving access to the complete queue.
7. The composition remains usable at 390, 414, 768, and 1440 CSS pixels, at 200% zoom, by keyboard and screen reader, and with reduced motion.
8. Owner and assistant receive the same read model subject to existing repository, RPC, RLS, and action-authority boundaries; Today introduces no mutation authority.
9. Automated unit, component, contract, type, lint, build, database, and browser checks pass before release evidence is requested.
10. Authenticated Judith-owner, assistant, physical iPhone 11 Safari, installed-PWA, recovery, deployment, and production-smoke evidence remain distinct release gates.

## System Invariants

- Today is a read model, not a new source of truth.
- Durable priority comes from `AttentionRepository`; Today does not rescore canonical attention items.
- Repository failures are isolated by source and represented as unavailable.
- Provider secrets, raw payloads, UUIDs, implementation event names, and restricted message content never enter the UI projection.
- External sends, pipeline mutations, nurture transitions, and provider actions remain governed by their existing approval and connector paths.
- Local checks do not certify authenticated, physical-device, provider, deployment, or production state.
