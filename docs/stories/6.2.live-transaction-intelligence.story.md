# Story 6.2 — Live Transaction Intelligence

## Status

Done

## Story

As an independent realtor, I need verified deal financials to appear in Insights from my live workspace so that volume, GCI, commission, expenses, forecast, and source ROI support daily business decisions without invented values.

## Acceptance Criteria

1. A workspace-scoped transaction ledger stores the linked contact, transaction status, representation side, property, source snapshot, close dates, sale price, GCI, net commission, marketing cost, other expenses, actor, and immutable idempotency key.
2. Active owner and assistant memberships may read and create workspace transactions; another workspace, a revoked member, or a caller-supplied workspace cannot access them.
3. Creating an under-contract or closed transaction updates the linked contact pipeline stage in the same database transaction.
4. Insights reads the live ledger on every dynamic render and shows closed volume, closed GCI, net commission, tracked expenses, net income, active forecast, deal count, and source ROI for the selected period.
5. Empty live ledgers show truthful zero-state metrics and an actionable deal form. Missing schema or failed reads remain visibly unavailable and never render fabricated zeroes.
6. Money is stored as integer cents, dates are explicit calendar facts, and every aggregate has a documented formula.
7. The transaction section is responsive at 390, 768, and 1440 pixels, keyboard accessible, and consistent with the premium internal CRM palette.
8. Domain, repository, action, component, migration, RLS, lint, typecheck, test, and build gates pass before release.

## Evidence Rules

- Closed-period metrics include only transactions with `status = closed` and `closed_at` inside the selected period.
- Active forecast includes explicit GCI values on pending and under-contract transactions; it is not a probability-weighted estimate.
- Net income equals net commission minus marketing cost minus other tracked expenses.
- Source ROI equals `net income / marketing cost`; it is unavailable when no marketing cost is recorded.
- Zero is shown only after a successful live ledger read.
