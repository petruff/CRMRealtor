4. Security checks cover workspace isolation, owner-only configuration, service-only provider admission, signed intake, replay, idempotency, optimistic concurrency, secret isolation, and sanitized receipts.
5. Property, transaction, financial, attention, attribution, consent, provider, and AI facts expose source, time, authority, and explicit unknown state without unsupported readiness or outcome claims.
6. Error, empty, blocked, unavailable, stale, revoked, disconnected, and recovery states remain actionable and human-readable; no ordinary user view exposes internal IDs, hashes, scopes, raw payloads, event keys, or implementation jargon.
7. Google, Mailchimp, texting, website intake, IDX/RESO, CMA, and Gemini each show independent implemented, configured, connected, reconciled, UAT, and released truth where applicable.
8. Production release is blocked by any P0/P1 core defect, failed recovery evidence, unresolved cross-workspace exposure, provider contradiction, or broken Judith critical journey.
9. Final evidence distinguishes local sample-mode checks, local authenticated/RLS checks, real-account provider checks, physical-device UAT, deployed smoke, and production release.
10. Repository artifacts, code, migrations, tests, comments, commit messages, and release documentation remain English-only.
