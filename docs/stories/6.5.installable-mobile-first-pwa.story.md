# Story 6.5 — Installable Mobile-First PWA

## Status

Ready for Review

## Story

As a realtor moving between office work and showings, I need Omnix to install like a trusted mobile app, open in a focused standalone window and recover gracefully from connectivity loss without exposing client information in browser caches.

## Acceptance Criteria

1. Omnix exposes a valid standalone web app manifest with branded 192 px, 512 px, maskable and Apple touch icons.
2. Chrome, Edge and Android can surface the native install prompt; iOS receives clear Add to Home Screen guidance.
3. Installed mode respects top, bottom, left and right safe areas without covering navigation or primary actions.
4. The service worker caches only the public offline shell, branded public assets and immutable framework assets.
5. Authenticated HTML, RSC payloads, API responses, auth routes, mutations and customer records are never written to the service-worker cache.
6. A full navigation without connectivity resolves to a branded, public, privacy-explaining offline state.
7. Online/offline and update-ready states are understandable, accessible and do not interrupt data entry without user confirmation.
8. Existing authenticated and public routes retain their mobile-first layout, keyboard behavior, reduced-motion support and desktop presentation.
9. Focused PWA tests, the complete regression suite, lint, typecheck and the production build pass.
10. Installability and standalone behavior are verified against a production deployment before release closure.

## Evidence Rules

- Installability requires a production-served manifest, fetchable icons and an active service-worker registration.
- A manifest alone does not prove an installable PWA.
- No production customer data may be copied into local audit artifacts or runtime caches.
- Browser screenshots do not prove offline cache safety; source and runtime cache inspection are both required.
- Existing user changes and private production screenshots remain outside release commits.
- All repository content and GitHub history remain English-only.
