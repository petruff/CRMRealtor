# Story 5.3: Omnix Grounded Web Research Agent

**Status:** Ready for Review
**Owner:** Product / Architecture / Engineering
**Requested:** 2026-09-01

## User Story

**As a realtor using Omnix,**
**I want to ask broad questions and research current public information with Gemini,**
**so that Omnix can help beyond the fixed CRM grammar without confusing public web content with client records or silently changing the business.**

## Acceptance Criteria

1. A question that does not map to an authorized deterministic CRM intent may use the configured workspace Gemini model with Google Search grounding.
2. CRM questions continue through the existing deterministic, workspace-scoped evidence path. Web research receives only the user's question; no contact, note, transaction, connection, secret, or workspace row is included.
3. A successful web-research answer includes bounded HTTPS sources returned by Gemini grounding metadata, a checked-at timestamp, the configured model, and an explicit read-only boundary.
4. Web content is treated as untrusted information and cannot grant tools, reveal prompts/secrets, mutate CRM data, or bypass the existing proposal/approval workflow.
5. The existing durable reservation, per-run ceiling, daily workspace ceiling, timeout, terminal receipt, prompt guard, owner-managed credential, and fail-closed behavior cover routing plus research.
6. If Gemini is unavailable, the provider is not Gemini, grounding has no valid sources, the budget receipt cannot be reserved/finalized, or the provider response is invalid, Omnix returns a truthful limited state and performs no mutation.
7. The CLI supports the same research fallback before UI adoption and emits a stable JSON envelope without logging the question or API key.
8. The UI distinguishes `Live CRM`, `AI grounded`, and `Web researched`; external sources open safely in a new tab and internal citations remain in-product links.
9. High-stakes answers are presented as general information and instruct the user to verify legal, financial, medical, or regulatory decisions with a qualified source.
10. Tests prove provider request minimization, source validation/deduplication, prompt-injection refusal, budget finalization, failure paths, CLI parity, external-link safety, and no regression of deterministic CRM questions.

## Non-Goals

- Unrestricted autonomous browsing, arbitrary custom tools, scraping, or URL fetching supplied by retrieved content.
- Sending messages, changing pipeline, creating tasks, or executing provider actions from a research answer.
- Claiming universal correctness or replacing licensed legal, financial, medical, brokerage, MLS, or compliance advice.
- Sending CRM rows to a web-grounding request.

## Architecture Decision

The deterministic CRM executor remains authoritative for workspace facts and governed actions. Public research is a separate read-only adapter invoked only after deterministic parsing and Gemini CRM routing do not produce an authorized CRM query. It receives the normalized question only, enables Gemini's server-side Google Search tool, accepts only provider-returned HTTPS grounding sources, and never enters the proposal executor. One durable budget reservation spans optional routing and research, and the answer is withheld if the terminal receipt cannot be persisted.

## QA Verdict

**PASS locally; production activation not claimed.** The implementation keeps CRM and web trust domains separate, sends only the question to Google Search grounding, accepts only credential-free HTTPS sources, reuses the durable budget reservation, withholds content if the terminal receipt fails, and does not expose an action path from research results.

- Focused agent/research/UI suite: 33 tests passed.
- Full suite: 253 files / 1,220 tests passed after the final router-null classification increment.
- `npm run lint`: passed.
- `npm run typecheck`: passed.
- `npm run build`: passed.
- Real CLI provider proof: blocked before provider dispatch because `OMNIX_SUPABASE_ACCESS_TOKEN` is not available in the local CLI environment. No Gemini request, CRM mutation, or cost was produced by that attempted proof.

## Completion Notes

- Unsupported natural language is first classified by Gemini as either one allowlisted CRM query or no CRM route. A valid no-route result enters public research; invalid or invented CRM commands still fail closed.
- Public research enables only Gemini's `google_search` built-in tool. It does not expose function calling, code execution, URL tools, credentials, CRM repositories, or connector actions.
- Answers without valid grounding sources are withheld. Sources are deduplicated, capped, HTTPS-only, and rendered as external links with `noopener noreferrer`.
- The member sees explicit `Web researched` language instead of `Live CRM`; internal CRM citations retain their existing presentation.
- This is a broad read-only research agent, not a guarantee of universal correctness and not an autonomous action agent. Existing governed proposals and owner approvals remain the only action boundary.
