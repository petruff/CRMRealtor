# Story 9.3 — Licensed IDX/RESO Adapter Foundation

**Epic:** 9 — Property Intelligence and Lead Conversion
**Status:** Locally Complete — Licensed Provider UAT Conditional
**Owner:** @architect + @data-engineer + @dev
**Quality Gate:** @qa + @devops

## Story

As a Florida realtor, I need Omnix to integrate listing data only after documented provider authority exists, so that property intelligence can reconcile permitted facts without fabricating access, retaining prohibited data, or exposing licensed content after rights change.

## Acceptance Criteria

1. A provider-neutral contract supports bounded pagination/cursors, changed-record reconciliation, deletion notices, source timestamps, and explicit retry outcomes.
2. Provider authority records workspace, rights reference, effective/expiry dates, credential binding reference, display/retention/deletion policy, attribution, freshness, and lifecycle state.
3. The default adapter and every unconfigured workspace remain disabled and perform no network request.
4. Only an owner can configure or revoke provider authority; activation requires a complete rights and credential binding record.
5. Only a service worker can claim/finalize synchronization, and replay or concurrency cannot create duplicate runs.
6. Licensed records retain provider identity, remote identity, payload hash, cursor/run evidence, permission state, display/retention limits, and deletion state without storing unrestricted raw provider payloads.
7. Revocation immediately stops synchronization and marks provider facts non-displayable while preserving minimum audit evidence.
8. Cursor, page size, record count, text, URL, timestamp, and retry inputs are bounded and fail closed.
9. Manual property operation remains available when licensed data is disabled, suspended, expired, or revoked.
10. Migration replay, rollback/forward repair, pgTAP/RLS, domain, adapter, repository, configuration UI, and recovery evidence pass before any live provider activation.
