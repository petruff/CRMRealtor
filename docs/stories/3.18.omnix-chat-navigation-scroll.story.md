# Story 3.18 — Omnix chat navigation and scroll

**Epic:** 3 — CRM operating foundation  
**Status:** InReview  
**Owner:** @dev (Vulcan)  
**Quality Gate:** @qa (Argus)  
**Created:** 2026-08-14

## Story

**As a CRM user,**  
**I want** the Omnix assistant conversation to remain navigable as messages grow,  
**so that** I can read earlier answers, return to the latest response and keep the composer available on every supported viewport.

## Acceptance Criteria

1. The floating Omnix dialog has a bounded viewport at mobile and desktop sizes, with only the conversation region scrolling.
2. The conversation exposes a visible, themed vertical scrollbar, stable gutter, keyboard focus and contained overscroll.
3. New questions and responses move the conversation to the latest entry without moving keyboard focus.
4. A labeled “Jump to latest” control is available when the session has messages.
5. The header and composer remain visible while the conversation scrolls, including short mobile viewports and safe-area insets.
6. Opening the modal prevents background-page scrolling and closing/unmounting restores the previous body overflow value.
7. Escape, focus trapping, reduced motion, existing prompts, clear session and grounded-response behavior remain intact.
8. Focused interaction tests, lint, typecheck, full tests and optimized build pass.
