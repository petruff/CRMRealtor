# Story 6.6 — Mobile Layout Perfection

## Status

Done

## Story

As a realtor using Omnix between appointments, I need every public and authenticated screen to reflow cleanly on a phone so navigation, sign-in, forms, data and primary actions remain readable and touchable without overlap or horizontal page scrolling.

## Acceptance Criteria

1. Public welcome and sign-in headers keep the theme control, brand and sign-in actions visible without overlap from 360 px through tablet widths.
2. Every primary authenticated route fits a 390 px viewport without document-level horizontal overflow or controls hidden behind fixed navigation.
3. Forms, date fields, filter bars, tables, cards, dialogs and empty states reflow or expose an explicitly labeled local scroll region when their content cannot safely stack.
4. Sticky headers, utility menus, assistant controls, install/update notices and bottom navigation respect safe areas and do not cover primary content or one another.
5. Interactive controls retain at least 44 px touch targets, visible focus treatment and understandable labels.
6. The mobile presentation preserves the established Omnix design system and desktop layout.
7. Reduced motion, zoom/reflow and keyboard behavior remain supported.
8. Responsive source checks, route-level browser checks, focused tests, lint, typecheck, the complete test suite and production build pass.
9. The corrected version is published and rechecked at production phone widths before closure.
